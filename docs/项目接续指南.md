## 2. 项目定位与关键事实

- Pek.ROutGuard＝企业内部**文件防泄漏（DLP）**双端产品，Cargo workspace：
  - `core/`（`pek-outguard-core`）：容器格式 `OGD1`、规则引擎、协议模型、密钥派生——**双端共享**。
  - `server/`（`pek-outguard-server`）：管理端（面板 + 客户端 API + 数据库 + 密钥托管），默认端口 **5600**。
  - `client/`（`pek-outguard-client`）：终端（Windows 服务 + 文件监控 + 加密执行 + 受控打开 + 防退出）。
- 文档：`docs/需求说明书.md`（待确认口径在第 9 章）、`docs/架构设计.md`（含容器字节布局与密钥体系）。
- **加密容器是唯一对外格式**：明文头（公司信息/提示语/密级）+ AES-256-GCM 分块密文 + 尾部 KeyBlock + SHA-256 记录。
- **规则只由服务端下发**，客户端只执行；规则集与终端组多对多（多人共用规则）。
- **安全边界**：用户态方案不对抗本地管理员 + 内核工具/重装系统；不做进程注入/反杀软/键盘记录。

## 3. 构建 / 测试 / 打包

- 工具链：edition 2024；Windows 为主目标。
- 依赖（path，相对 `../`）：`dhrust=../DH.RustBase`、`pek-rcode=../Pek.RCode`、`pek-radmin=../Pek.RAdmin`、`pek-rwaf=../Pek.RWaf`——**编译报缺 API 时先拉新这几库再复测**。
- 日常：`cargo check`；调测：`cargo build --profile fast`；发版：`cargo build --release`。
- 回归：`cargo test`（每轮收尾必跑，贴实际输出）。

## 4. 提交与推送

- 提交说明用中文；`git commit -F <UTF-8 文件>`（不要用 `-m` 传中文，PS 5.1 会变 gb2312）。
- GitHub 推送遇 hosts 劫持用 IP 直连：`git -c http.curloptResolve=github.com:443:<IP> push origin main`。
- 每轮收尾三件套：① 决策记录新增节（含用户原话）② `tools/continuity/sync-memory.ps1` 回灌 `docs/项目记忆.md` ③ 回归验证如实汇报。

## 5. 状态快照（2026-10-26）

- 阶段：**M1 双端闭环 + 客户端服务化/自动加密已完成**；Tauri 客户端 UI 与服务端多用户待做。
- 已完成：
  - `core`：`container`（OGD1）、`crypto`（HKDF/包裹）、`rules`（三级判定 + 系统保护区）、`protocol`、`signature`、`machine`。
  - `server`：配置/主密钥/数据库（Pek.RCode 四表）/客户端 API/面板（登录/概览/终端准入/规则集/审计）。
  - `client`：配置（密码 enc:v1）、注册、策略同步、手工/自动加密、受控打开、**服务化（install/uninstall/start/stop/restart）+ 失败恢复策略 + 卸载授权校验 + notify 监控（800ms 去抖）+ 事件上报（30s）**。
- 验证基线：`cargo test --workspace` **67 passed**；`cargo clippy --workspace --all-targets -- -D warnings` 零告警；自动加密全链路实测通过（决策记录第 10 节）。
- 未开始（M1 剩余）：客户端 Tauri 配置界面 + 双进程互保 + 服务 ACL + 卸载令牌；服务端多用户/权限/WAF/星尘/打包。
- 待用户确认：需求文档 Q1–Q8（已按建议值暂定，见决策记录 1.8）。
- 仓库尚无 git 远程（提交后需建仓再 `git push -u origin main`）。

### 5.1 本机双端冒烟

```powershell
# 服务端
$env:PEK_OUTGUARD_BASE='<临时目录>'; .\target\debug\pek-outguard-server.exe
# 客户端（另开终端）
$env:PEK_OUTGUARD_CLIENT_BASE='<临时目录>'
.\target\debug\pek-outguard-client.exe config set --server http://127.0.0.1:5600
.\target\debug\pek-outguard-client.exe register      # 面板准入后再 sync
.\target\debug\pek-outguard-client.exe sync
.\target\debug\pek-outguard-client.exe encrypt D:\Work\合同.docx
```
