# Pek.ROutGuard 需求说明书

> 版本：v0.1（2026-10-26）· 状态：**待用户确认关键口径后定稿**
> 本文把用户口述需求补全为可开发、可验收的规格；"待确认"项集中在第 9 章。

## 1. 背景与目标

企业内部大量敏感文档（合同、图纸、报价、研发资料）以明文形式存放在员工电脑与共享盘，存在误发、主动外传、离职带走等风险。本产品提供"**文件出不去、出去打不开、打开有痕迹**"的闭环：

| 目标 | 衡量方式 |
|---|---|
| 受控文件离开授权终端后不可读 | 未装客户端的电脑双击/用 Office 打开均为乱码或提示页 |
| 授权终端内可用 | 双击自动解密打开，保存自动重新加密，用户几乎无感 |
| 规则集中管理 | 管理员改规则 → 终端在心跳周期内生效，回执可查 |
| 行为可审计 | 加密/解密/打开/拒绝/外发/篡改事件均可按人、按终端、按时间查询 |
| 终端常驻不可随意退出 | 普通用户无法停止服务/卸载；仅服务端授权卸载 |

## 2. 角色

| 角色 | 职责 |
|---|---|
| 超级管理员 | 系统设置、管理员与角色、密钥轮换、卸载授权 |
| 策略管理员 | 规则集、策略绑定、灰度发布 |
| 审批人（部门主管） | 外发/解密审批 |
| 审计员 | 只读查看审计与告警 |
| 普通员工（终端用户） | 自动加密、受控打开、提交外发申请 |
| 外部接收方 | 未装客户端；只能看到"已加密"提示，或使用审批生成的外发包 |

## 3. 术语

- **规则（Rule）**：一条匹配条件 + 一个动作（加密/放行/阻断/仅审计）。
- **规则集（Policy Set）**：一组有序规则 + 默认动作 + 加密参数，有版本号，可被多个终端组共享。
- **终端组（Group）**：一组终端（按部门/项目），规则集绑定到组即"多个人共用同一规则"。
- **受控文件**：已加密的容器文件，扩展名可配（默认 `.ogd`）。
- **受控打开**：已装客户端在本机把容器解密到受控临时目录，用授权程序打开，关闭后清理。
- **外发包**：审批通过后生成的、带有效期/次数/水印的独立可执行包或受密码保护的独立文件。

## 4. 功能需求

### 4.1 服务端（Server）

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-S-01 | 终端注册与准入：安装即注册；支持"注册码/管理员审批"两种准入 | 未准入终端拿不到策略，界面显示"待审批" |
| FR-S-02 | 终端管理：在线状态、主机名、登录用户、客户端版本、策略版本、最后心跳、分组 | 列表可按组/在线/版本筛选 |
| FR-S-03 | 组织管理：部门/终端组/用户，用户与终端多对多 | 一人多机、一机多人（共用电脑）均支持 |
| FR-S-04 | 规则集管理：规则明细（匹配条件/动作/优先级）、默认动作、版本、启用状态 | 同一规则集可绑定多个组；改规则自动升版本 |
| FR-S-05 | 策略下发：按版本拉取；支持灰度（指定终端先行）；终端回执确认 | 未回执终端在面板高亮并告警 |
| FR-S-06 | 密钥管理：主密钥生成/备份/轮换；每规则集独立策略密钥；终端密钥登记 | 轮换后旧文件仍可解（保留历史密钥版本） |
| FR-S-07 | 审计：终端事件汇总、服务端操作审计、按人/终端/规则/时间检索、导出 CSV | 审计不可修改；分页 500 条上限 |
| FR-S-08 | 外发审批：申请（文件/原因/接收方/有效期）→ 审批 → 生成外发包/明文包 → 可吊销 | 有效期与次数生效；吊销立即失效 |
| FR-S-09 | 卸载授权：管理员为目标终端签发一次性卸载令牌（含机器码 + 有效期 + 签名） | 无令牌卸载被拒并上报 |
| FR-S-10 | 告警：离线超期、策略未回执、客户端被篡改、异常解密频率、卸载尝试 | 面板告警卡 + 可选企业微信/钉钉推送 |
| FR-S-11 | Web 面板：概览/终端/用户与组/规则集/策略/审计/审批/密钥/设置/数据库 | 深色风格，权限按角色渲染（越权 403） |
| FR-S-12 | 系统能力：日志、配置热生效、数据库管理（只读 SQL/备份/还原）、WAF、星尘托管、在线升级 | 与生态其他服务一致 |

### 4.2 客户端（Client）

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-C-01 | 安装注册：静默安装（MSI/EXE），首次启动自动注册并领取策略 | 全程无需人工填服务端地址（安装参数可预置） |
| FR-C-02 | 系统服务：LocalSystem 运行、开机自启、崩溃自动重启 | 任务管理器结束进程后 < 30s 自动恢复 |
| FR-C-03 | 防关闭/防卸载：服务恢复策略、双进程互保、服务 ACL 限制 STOP、卸载需服务端令牌 | 普通用户停止/卸载均失败并上报；管理员带令牌可卸载 |
| FR-C-04 | 完整性自校验：程序与配置哈希、签名校验；异常则自愈并上报 | 修改 exe 或规则缓存 → 事件上报 + 恢复 |
| FR-C-05 | 文件监控：受控目录/磁盘按规则监控创建、写入完成、重命名、移动入受控区 | 1000 文件批量写入不丢事件、不重复加密 |
| FR-C-06 | 规则引擎：扩展名/文件名/路径/来源进程/大小上限/排除项；与服务端同序解析 | 客户端与服务端对同一输入的判定一致（共享 core 实现） |
| FR-C-07 | 加密执行：AES-256-GCM 分块流式加密、容器头写入公司信息、原文件安全删除 | ≥ 4GB 文件可处理；中断不产生半成品（临时文件 + 原子替换） |
| FR-C-08 | 受控打开：双击/右键"安全打开"→ 解密到受控临时目录 → 默认程序打开 → 关闭后清理 | 临时明文不残留；未授权进程无法读取受控目录 |
| FR-C-09 | 保存回流：授权程序"另存为/导出"到受控路径的文件自动重新加密 | 另存到桌面/ U 盘同样加密 |
| FR-C-10 | 明文外带限制：复制到剪贴板、打印、拖拽、截屏给出提示与审计（首版提示 + 审计，不做硬阻断） | 事件可查；策略可升级为阻断（后续） |
| FR-C-11 | 离线模式：策略缓存 + 宽限期（默认 7 天）；超期后按配置"允许只读/禁止打开" | 断网 7 天内正常；超期行为符合配置 |
| FR-C-12 | 事件上报：本地队列 + 批量上报 + 断网缓存 + 重传去重 | 断网 24h 事件不丢；恢复后按序上报 |
| FR-C-13 | 托盘 UI：状态、策略版本、最近事件、外发申请、关于（不提供"暂停保护"） | 无法从 UI 退出保护 |
| FR-C-14 | 自动升级：服务端下发升级包（签名 + 哈希），影子替换 + 失败回滚 | 升级期间不丢加密任务 |

### 4.3 目标文件格式判定（用户重点）

- 加密/不加密**完全由服务端规则决定**，客户端只执行。
- 规则匹配维度（全部可选、可组合）：
  1. 扩展名（`docx/xlsx/pptx/pdf/dwg/…`，支持通配 `*`）
  2. 文件名模式（通配符）
  3. 路径前缀（如 `D:\Work`、`\\nas\项目`）
  4. 产生/写入进程（`winword.exe`、`wps.exe`、`acad.exe`，支持通配）
  5. 文件大小上限/下限（可选）
  6. 排除项（系统目录、编译缓存、临时文件）
- 动作：`Encrypt`（强制加密）、`Plaintext`（明确放行）、`BlockWrite`（禁止落盘）、`Audit`（仅记录）。
- 冲突解析（**明确口径**）：路径排除 > 显式放行 > 优先级数值高者 > 先匹配者胜出 > 默认动作（默认 `Plaintext`，避免误伤；管理员可在规则集上改默认 `Encrypt`）。
- 规则变更后：
  - 新建/修改文件立即按新规则执行；
  - 存量明文文件：需管理员显式发起"补加密扫描"（客户端分频、限速，避免占满 IO）。

### 4.4 共享与权限（用户重点）

- 规则集与终端组/终端/用户是**多对多**：一个规则集可绑定多个部门；一个终端可叠加多个规则集（按绑定优先级合并，冲突按 4.3 解析）。
- 终端用户登录多账号共用电脑时，按"终端绑定 + 用户绑定"取并集，用户级规则优先。
- 面板权限：`clients / policies / audit / approvals / keys / settings / database` 七个权限点，内置 admin 拥有全部。

## 5. 非功能需求

| 类别 | 指标 |
|---|---|
| 加密吞吐 | ≥ 100 MB/s（NVMe，单文件 1GB，release） |
| 客户端资源 | 空闲 CPU < 1%（单核）、内存 < 80 MB、无周期性全盘扫描 |
| 服务端资源 | 1000 终端在线时心跳处理 < 5% 单核；事件写库批量提交 |
| 心跳 | 默认 60 s；**只发变化项**（未变化字段为 null，服务端保留旧值） |
| 策略生效 | 改规则后 ≤ 2 个心跳周期（默认 ≤ 2 min） |
| 恢复能力 | 客户端进程被杀后 ≤ 30 s 自恢复；服务端崩溃重启后会话不丢 |
| 文件规模 | 单文件 ≥ 4 GB；路径长度 ≥ 260 字符（Windows 长路径前缀） |
| 平台 | 首版 Windows 10/11 + Server 2016+（x64）；Linux/国产化为后续阶段 |
| 安全 | AES-256-GCM；Ed25519 请求签名 + 时间戳 + nonce 防重放；HTTPS（自签叶子证书或反代 TLS） |
| 可运维 | 卸载令牌、批量静默安装、日志轮转、数据库备份还原 |

## 6. 安全边界（必须如实告知客户）

1. **用户态强度**：本产品首版为**用户态受控方案**。能防住：普通员工误发、主动拷贝到未装客户端电脑、离职带走加密文件。**防不住**：拥有本地管理员权限的人用内核工具、PE 修改、重装系统、拆盘取证。
2. **透明加密分级**：
   - A 级（首版）：容器加密 + 受控解密打开。文件静态始终是密文；打开瞬间在受控目录产生临时明文。
   - B 级（后续可选）：Windows minifilter 内核驱动，对白名单进程透明解密、对非白名单进程返回密文。需 C++/WDK 开发 + EV 代码签名 + 蓝屏风险控制，**不在首版范围**。
3. **不做**：进程注入、反杀软对抗、键盘记录、远程截屏监控、隐藏进程。
4. **卸载保护**：依靠服务恢复策略 + 双进程互保 + 服务 ACL + 服务端令牌，属于"合规管控"而非"不可破解"。

## 7. 分期计划

| 阶段 | 内容 | 交付 |
|---|---|---|
| **M1 核心闭环** | 服务端注册/终端/规则集/策略下发/审计；客户端服务化 + 监控 + 加密 + 受控打开 + 事件上报 | 可演示：加密文件外发打不开、本机可打开、规则改动生效 |
| **M2 管控增强** | 外发审批 + 外发包 + 水印 + 卸载令牌 + 离线宽限期 + 告警推送 + 自动升级 | 可交付企业试点 |
| **M3 可选增强** | 内核透明驱动、屏幕水印、打印管控、Linux/国产化、U 盘管控 | 按客户需求评估 |

## 8. 验收标准（M1）

1. 安装客户端后，向受控目录保存 `docx` → 文件变为 `.ogd` 且源文件消失；拷贝该文件到未装客户端电脑 → 用 Word 打开失败，用记事本可见公司信息头。
2. 在已装客户端电脑双击 `.ogd` → 用 Word 正常打开；编辑并保存 → 磁盘上仍是加密容器（临时目录清理后无明文残留）。
3. 服务端把 `pdf` 加入加密规则 → 2 个心跳周期内客户端生效 → 新建 PDF 自动加密。
4. 同一规则集绑定 3 个部门，3 个部门终端均按同一规则执行；修改规则后 3 个终端版本号同步更新并回执。
5. 普通用户 `sc stop` / 结束进程 / 控制面板卸载 → 失败并产生审计事件；管理员签发卸载令牌后可正常卸载。
6. 断网 24 小时：加密与打开正常；恢复网络后事件完整入库（无重复、无丢失）。
7. 服务端审计可按"终端 + 时间 + 事件类型"查询并导出。

## 9. 待确认口径（**开发前必须确认**）

| 编号 | 问题 | 备选 | 建议 |
|---|---|---|---|
| Q1 | 客户端首版平台 | 仅 Windows / Windows+Linux | 仅 Windows（Linux 用 inotify 同架构，可增量做） |
| Q2 | 加密层级 | A 用户态容器 / B 内核透明驱动 | **A**（B 需 C++/WDK + 签名，工期与风险高一个量级） |
| Q3 | 透明打开方式 | 解密到受控临时目录 / 虚拟盘（Dokan/WinFsp） / 进程注入 Hook | 受控临时目录（工程可控；虚拟盘需额外驱动） |
| Q4 | M1 是否含外发审批 | 含 / 后置 | 后置到 M2（M1 先跑通加密闭环） |
| Q5 | 服务端部署形态 | 星尘托管单机 / 多节点 | 星尘托管单机（与生态一致） |
| Q6 | 加密算法 | AES-256-GCM / 国密 SM4 | AES-256-GCM（`dhrust::secret` 已有；SM4 需新增依赖与合规评估） |
| Q7 | 默认动作 | 默认放行 / 默认加密 | 默认放行（防误伤）；客户可改 |
| Q8 | 是否要求"复制/打印硬阻断" | 提示+审计 / 硬阻断 | M1 提示+审计，M2 可升级 |
